# 视觉与拉片输入

## 角色概念设计

为 `CHAR-001` 设计一张综合角色设定板。角色是 34 岁县城公交维修工，身形精瘦，长期户外工作；已确认锚点只有深绿色维修夹克、左胸磨损工牌袋、右手食指旧绷带和克制疲惫的气质。发型、具体五官、鞋款和夹克内搭均未确认。不要把新增细节写成已确认事实。

设定板需要正面全身、侧面全身、面部近景、夹克结构和右手绷带细节。中文标题与标签应通过可靠排版完成；若无法可靠排版，交付无字底图和独立 UTF-8 标签文件。若无法生成图像，交付 `visual-brief-v001.md` 并标记 `prompt-only`。

## 视频拉片

对随任务提供的短视频做逐镜拉片，记录真实总时长、帧率、切点、每镜可见内容和声音。把实证、估算与未知分开；不要根据文件名推断画面。输出 `shot-analysis-v001.md`，机器可读记录可另存 JSON。
