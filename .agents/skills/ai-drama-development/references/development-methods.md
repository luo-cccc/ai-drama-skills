# 故事开发方法

## 概念开发

先输出以下内容，不直接扩写长篇正文：

1. 一句话故事：主角、目标、阻力、代价和最终选择。
2. 核心命题：故事用人物行动回答的问题。
3. 类型承诺：观众持续观看所期待的冲突、情绪或信息机制。
4. 视觉记忆点：能反复变化且参与剧情的场景、动作、物件或声音。
5. 2–3 个方向：分别改变人物引擎、世界引擎、叙事引擎或结局路径。
6. 推荐方向：给出明确选择、依据、制作难点和开发风险。

每个方向包含：主角与目标、核心冲突、关键规则、三个关键节拍、高潮行动、结局状态、受众、制作难度。不要用“都可以”回避判断，不要用虚构市场数据证明商业潜力。

## 世界规则

为每条重要规则写明：

`规则｜受益者｜受损者｜执行方式｜违反代价｜可触发事件`

覆盖与故事有关的时间地域、社会或行业结构、公开规则、隐藏规则、信息流通、资源边界、禁忌与代价。奇幻、科幻和悬疑规则同时回答“能做什么、不能做什么、代价是什么”。删除不影响人物选择的背景堆砌。

## 人物体系

为核心人物建立：

- 身份、社会位置、现实资源、外显行为和语言习惯；
- Want、Need、Fear、Secret、Weakness、底线和能力；
- `起始信念 → 诱发事件 → 错误策略 → 代价累积 → 关键认知 → 最终选择 → 新状态`；
- 与其他角色的表面关系、实际需求、隐藏矛盾、权力变化和关系终点。

让配角拥有独立目标和信息权限。让对抗者拥有自洽目标与有效策略。用角色选择证明性格，不用小传中的形容词代替剧情表现。

## 结构与节拍

用以下最小节拍链设计事件：

`角色目标 → 当前阻力 → 主动策略 → 意外后果 → 新信息或新代价 → 下一步选择`

根据媒介选择结构：

- 电影或中长片：建立不可逆进入、中点重估、错误策略反噬、最低点选择、高潮行动与结局变化。
- 剧集：建立季度主线、单集目标、A/B/C 线关系、阶段性钩子和长期关系变化。
- 网络短剧：尽快建立可见异常和当集冲突；每集解决一个小问题并提出更大问题；用信息、权力、代价或未完成行动形成集尾动力。
- 广告剧情：让产品或主题进入行动因果，用可见结果呈现价值；未获授权时不虚构品牌、代言或市场事实。

结构模型只用于解释当前故事。避免为了匹配模板强加反转、支线或固定比例。

## 场次与制作约束

为每个候选场次写明：时空、人物、目标、阻碍、行动、信息、关系变化、转折和离场动力。删除或合并没有目标、冲突或状态变化的场次。

同时检查场景数量、群众、车辆、特效、夜雨、水火、高空、动物和复杂动作是否符合制作规模。低预算方案优先通过构图、遮挡、反射、声音、有限空间和表演建立视觉性。

## 开发验收

- 主角通过选择推动剧情，而非只被事件拖动。
- 阻力升级至少改变强度、时间、代价、盟友立场、目标冲突或信息判断。
- 反转存在前置证据，不依赖临时新增规则。
- 世界、人物、时间、场景和关键物件前后一致。
- 结局兑现核心命题，并展示人物或世界的可见变化。
