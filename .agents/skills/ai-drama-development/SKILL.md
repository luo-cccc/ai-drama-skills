# AI Drama Development

把不完整想法发展为因果清楚、人物驱动、可拍摄且可继续生产的故事基准。默认使用简体中文；服从用户明确指定的媒介、体量、受众和交付格式。

## 选择模式

只选择一个主模式；用户要求完整开发时按顺序组合，并分阶段交付。

| 模式 | 适用输入 | 主要产物 |
|:--|:--|:--|
| 概念开发 | 一句话想法、题材或模糊方向 | 核心命题、冲突、2–3 个真正不同的方向、明确推荐 |
| 故事开发 | 已有主角或事件骨架 | 世界规则、人物体系、因果结构、场次或分集规划 |
| 原创改编 | 参考作品、第三方素材或降低可识别相似性的请求 | 抽象价值提炼、风险表、独立的新故事引擎和验收 |

普通润色、忠实改编或已有剧本续写不要误路由到原创改编。需要正式提示包、分场或正文时，交给 `ai-drama-screenplay`；只需诊断已有文本时，交给 `ai-drama-script-audit`。

## 读取参考

- 执行概念、世界、人物或结构开发时，读取 [development-methods.md](references/development-methods.md)。
- 使用任何第三方素材、参考作品、真实人物或品牌，或用户要求原创化时，读取 [originality-and-rights.md](references/originality-and-rights.md)。
- 进入项目模式时读取 [workflow-contract.md](references/workflow-contract.md)；涉及权利边界时同时读取 [originality-safety.md](references/originality-safety.md)。
- 把心理与情绪转成可见表演或摄影线索时读取 [performance-camera.md](references/performance-camera.md)。

## 建立输入基准

1. 识别输入形态、目标媒介、时长或集数、受众、题材、制作规模和交付范围。
2. 区分用户提供的事实、合理推定和新创提案；不要把分析推断写成来源事实。
3. 检查主角、目标或冲突、关键关系、结局方向和基调，不使用字数门槛。
4. 只有概念时直接进入概念开发，不阻断任务。
5. 次要信息缺失时采用最小假设并显式列出；会改变题材、人物关系或结局时，只询问一个关键问题。

## 执行工作流

1. 提炼一句话故事、核心命题、类型承诺、观看动力和视觉记忆点。
2. 明确主角的目标、阻力、策略、失败代价和最终选择。
3. 让世界规则具体改变人物行动；写清能做什么、不能做什么及违反代价。
4. 建立主要人物的 Want、Need、Fear、Secret、Weakness、资源、底线和 Arc。
5. 用“目标 → 阻力 → 策略 → 后果 → 新信息/代价 → 下一选择”连接关键节拍。
6. 根据媒介调整密度，不机械套用三幕比例、固定页码或短剧反转数量。
7. 将抽象情绪落实为动作、选择、空间、物件或声音；仅在叙事需要时调用微表情、重心、动作中间态、生理反应和光影。
8. 检查因果、角色能动性、冲突升级、规则一致性、制作规模和下游可用性。

## 处理项目状态

- 在当前工作区向上查找 `project-state.json`。找到时按套件契约运行项目模式，读取已确认事实、继承版本与约束，并登记新产物和检查点。
- 未找到时运行独立模式；直接交付请求范围，不强制创建项目，不声称跨批次连续。
- 方向选择属于默认确认点。用户已明确选择方向或预授权连续执行时继续，并在项目模式记录授权。
- 把交付状态设为 `draft` 或 `pending-confirmation`；只有用户确认的具体版本才能设为 `confirmed`。

## 交付结果

概念开发至少交付：开发假设、2–3 个不同故事引擎、推荐方向、风险和下一阶段所需决策。故事开发至少交付：一句话故事、世界规则、人物关系与弧光、关键节拍、结局状态、制作约束。原创改编严格使用引用中的风险与独立性验收。

将正式开发产物保存为 `development-vNNN.md` 或同类英文稳定文件名，正文默认使用简体中文；不要把中文片名直接用作文件名。

不要提前写正式分场或伪装成已确认剧本。需要交接时，只列稳定的角色、场景、道具和母题候选；把新增细节标为“提案”，不要标为确认事实。

## 完成检查

- 确认每个关键事件由人物选择或既定规则引发。
- 确认不同方向改变了故事引擎、关系或结局路径，而非只换名称。
- 确认人物欲望、策略、代价和弧光实际推动剧情。
- 确认世界规则产生事件且没有临时为解决矛盾而改写。
- 确认未虚构市场数据、授权状态或法律结论。
- 确认产物清楚区分来源事实、推定和新创提案。
