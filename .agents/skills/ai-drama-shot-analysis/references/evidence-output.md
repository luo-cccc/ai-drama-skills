# Evidence And Output Format

## 证据等级

| 显示值 | 项目值 | 使用条件 |
|:--|:--|:--|
| `实证` | `confirmed` | 直接来自已检查的视频帧、媒体元数据或可听音轨 |
| `估算` | `inferred` | 来自有时长的有序描述，或画面支持但技术上不能唯一确认的判断 |
| `未知` | `unknown` | 来源缺失、分辨率不足、音频不可用或证据冲突 |

允许同一镜头的时间为实证、运镜为估算、人物身份为未知。给结论就近标记等级，不用一个镜头级标签掩盖字段差异。

## Markdown 结构

```md
## SCENE-001｜昏暗室内

### SHOT-001｜00:00:00.000–00:00:03.200

- 边界：实证｜硬切进入；硬切离开
- 摄影：实证｜中景、中距离、侧前方平视、固定镜头
- 画面：实证｜CHAR-001 停在门口，右手仍握住 PROP-001；窗光从画面右侧照入
- 运镜：未知｜无法确认轻微变化来自光学推近还是数字裁切
- 对白：实证｜林遥：“我到了。”
- 环境声：实证｜低频室内底噪
```

使用整数毫秒保存数据；Markdown 可以显示 `HH:MM:SS.mmm`，并保持与结构化时间完全一致。长片可按场景分批，但每批保留原视频绝对时间，不重置为零。

## 无可靠时间码

没有视频或可靠总时长时，不生成伪时间范围。改用 `顺序段 001`、`顺序段 002`，并将时间写为 `未知`；列出建立实测时间轴所需的视频或总时长。

## 资产和场景

- 回到先前空间时复用原 `SCENE-NNN`，不要因剪辑顺序重新编号。
- 仅为反复出现、承担叙事功能或需要复现的角色与道具分配稳定 ID。
- 把可见外观与推断身份分开；“穿深色外套的人”可以实证，姓名和关系可能仍为未知。
- 在独立模式中，这些 ID 只对当前报告有效；不要声称后续批次已锁定。

## 复盘与反向工程

用户要求节奏、摄影或 AI 复现建议时，在事实记录后另设“解释”和“建议”区：

- 解释可以归纳镜头长度、景别分布、构图变化、声音桥和信息释放，但标为分析结论。
- 复现建议必须引用对应 `SHOT-NNN`，不得把建议倒写成原视频事实。
- 不推断未授权的具体导演、摄影师、品牌或受保护风格来源。
