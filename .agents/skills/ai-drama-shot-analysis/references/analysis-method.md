# Video Analysis Method

## 技术顺序

1. 使用媒体探测工具读取时长、帧率、帧数、尺寸、画幅、编码和音轨。
2. 生成低频全片预览，识别场景与动作顺序。
3. 使用场景变化检测获取候选切点，不把检测结果直接当成最终边界。
4. 使用 `media_analysis_cli.py extract-frames` 为每个候选段抽取首、中、尾复核帧，再检查候选点前后多帧；对短镜头提高采样密度。
5. 逐帧调整确认后的镜头边界，重新抽取首、中、尾帧，并复查长镜内的焦点、机位或构图阶段变化。
6. 使用 `media_analysis_cli.py extract-audio` 提取独立音轨，再检查波形与实际听感，核对对白、音效、环境声、音乐和跨镜声桥。

优先使用发行包的 `scripts/media_analysis_cli.py` 调用 FFprobe/FFmpeg，统一来源哈希、媒体字段、候选切点、JSON 校验和 Markdown 渲染。工具不可用时降低证据等级，不用推测补齐。

## 边界判定

新建镜头或镜头段：

- 摄影机硬切到新画面。
- 场景或时间切换完成。
- 渐变、匹配、甩镜或遮挡转场进入新的稳定画面关系。
- 连续镜头中的主导景别、摄影机角度、运动方式或构图权力关系出现明确阶段变化。

不要因人物普通动作、单帧闪光、曝光波动、路人遮挡、物体擦镜、快速运动模糊或轻微手持变化机械拆镜。对疑似无缝转场记录判断依据和不确定性。

## 视觉字段

- 场景：可见空间类型、内外、时间线索、前中后景、结构、材质、天气和空气状态。
- 角色：可见年龄感、面部/发型、服装、配饰、动作、姿态和空间位置；不得断言真实身份、精确年龄、职业或关系。
- 摄影：大远景至大特写、远/中/近距离、正侧背/过肩/主观、平俯仰/顶视/倾斜。
- 运动：固定、手持、推拉、横移、跟拍、环绕、摇摄、升降、航拍、变焦和焦点转移。
- 构图：主体位置、遮挡、纵深、框中框、引导线、正负空间、视线留白、景深和焦点变化。
- 光影：主光来源、软硬、反差、轮廓/反射/窗光、阴影边缘和人物移动造成的明暗变化。
- 物理：只在可见接触时记录支撑、摩擦、重量、惯性和反作用力。

使用具体观察，避免“高级、震撼、电影感”等空洞评价。

## 声音字段

- 对白：只转写清楚可听的内容；听不清写 `[听不清]`。标记画外音和旁白。
- 字幕：不要用字幕替代听辨；需要时单列字幕与音轨差异。
- SFX：只写音轨中可辨认且与动作或空间有关的声音。
- 环境声：记录空间底噪、混响、人群、交通、风雨、机械等可听特征。
- 背景音乐：记录进入、延续、停止、音色、速度与强弱变化，不猜曲名。
- 完全静音且已经核实时写“无可辨识声音”；否则省略空字段。

## 精度验收

在具备逐帧访问的实证模式中，让已知硬切点误差不超过两帧。按 `frame_duration_ms = 1000 / fps` 计算容差；可变帧率素材优先使用逐帧时间戳，不用平均帧率制造虚假精度。
