# 分场与标准剧本契约

## 分场固定字段

每场写明：

| 字段 | 要求 |
|:--|:--|
| 场号 | 连续且稳定；连续场组或交叉剪辑仍保留一个主场号 |
| 场景标题 | 内/外景、单一地点、时间；多空间显式标记类型 |
| 出场人物 | 只列实际出现角色 |
| 戏剧任务 | 说明该场必须完成的叙事功能 |
| 开始状态 | 记录人物关系、信息或情绪进入状态 |
| 核心事件 | 写行动与结果，不写镜头方案 |
| 转折 | 说明结束状态相对开始状态的变化 |
| 必保元素 | 列出台词、动作、物件或母题及保留级别 |
| 场尾逻辑 | 写离场钩子或进入下一场的因果 |
| 备注 | 标记可压缩、不可压缩或可合并 |

分场属于编剧结构层。不要加入镜头号、景别、机位、运镜、灯光、演员调度或导演阐述。正文需要改变空间、核心事件、必保元素或场尾时，先登记差异并重新确认分场。

## 场标题

普通场严格使用：

```md
## 场 1｜内景 培训班素描教室 - 下午
```

场号连续；使用全角 `｜` 分隔；标题包含内/外景、地点和时间。不要混用 `## 1.`、`### 第一场` 或 `场景一`。

普通场只包含一个连续时空。人物或动作连续穿越相邻空间时使用：

```md
## 场 5｜连续场组 会议室B -> 行政办公室 - 日
```

同一时间并行发生在多个空间时使用：

```md
## 场 25｜交叉剪辑 出租车 / 萧尧住处 - 夜
```

多空间正文每次切换时写 `**空间：会议室B**`。不要用未标记斜杠合并不连续空间，也不要用连续场组掩盖时间跳跃。

## 动作与可拍性

- 使用现在时，一段只写一个连续动作或清晰画面。
- 写人物动作、视线、空间位置、道具状态、可听声音和合理光源变化。
- 把不可见心理转换为动作、停顿、物件、空间反应或旁白。
- 把回忆、想象和主观画面标明起止，不写“角色意识到”作为可拍动作。
- 仅在叙事转折、信息释放或关键表演处写必要镜头提示，不把正文变成逐镜分镜。
- 使用姓名或清楚指代；不要机械禁止自然代词，但任何指代都不得造成角色或动作归属歧义。

## 对白与屏幕文字

人物名单独加粗，下一行写对白：

```md
**姜宁**
时间到了，画笔放下。从第一排开始交卷。
```

不要写成 `姜宁：时间到了`，也不要把人物名和动作混在同一行。画外音使用 `**姜宁（画外）**`。

微信、短信等屏幕文字使用引用格式：

```md
> **姜宁（微信）**
> 看完了。标注了23处。
```

让对白服务获取、掩盖、阻止、试探或迫使选择。删除重复画面信息的说明性台词；通过用词、句长、停顿、回避和攻击方式区分人物。

## 正文约束

- 逐场服从已确认提示包与分场，不静默改变人物关系、关键动机、事件、结局或必保元素。
- 不无依据新增第三者、怀孕、车祸、绝症、死亡、绑架、黑化、复仇或强反转。
- 不删除承担伏笔回收的场景、台词、物件或母题。
- 不把分析、自检、创作说明或下游分镜混入纯剧本正文。
- 每稿单独保存并接受证据化审计；只有已确认具体版本才能进入正式分镜和锁定资产。
