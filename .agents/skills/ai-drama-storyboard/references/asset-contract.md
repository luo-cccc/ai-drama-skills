# Asset And Continuity Contract

Create stable IDs for elements reused across scenes, requiring continuity, or causing a material plot consequence. A causally critical prop gets a stable asset even if it appears only once. Do not turn unrelated background people into one stable character.

## Asset Types

- Character: identity, age range, anatomy, face, hair, wardrobe stages, performance anchors.
- Scene: structure, entrances, fixed furniture, materials, light direction, time variants.
- Prop: form, material, ownership, state, interaction, narrative function.
- Motif: repeated image, sound, object, action, or spatial pattern and its development.
- Costume: character, story phase, garment, hair/makeup, body state, and continuity range.
- Background group: non-identical extras with a shared production function.

Separate narrative function from observable visual features. Avoid empty adjectives such as “premium” or “cinematic” unless translated into materials, light, construction, or composition.

## Continuity

Record only changes that affect later execution: wardrobe, injury, dirt, moisture, object ownership, opening state, position, damage, light state, and spatial relationship. Each event identifies scope, asset, field, previous value, new value, and evidence.

Reuse the base ID for temporary states. Create a variant only for a stable visual version intended for repeated reuse.

## Visual DNA

Write positive identity anchors, state-dependent anchors, and prohibited drift. Do not invent unknown continuity-critical facts to complete a table. Mark proposals as `inferred` and keep them unlocked until confirmed.
