# Storyboard Delivery Profiles

## Governed Profile Fields

In project mode, read `aspect_ratio`, generator, audio, subtitle, editing, and visual-reset policy from the active project or target delivery profile. Do not hard-code `16:9` or infer a ratio from the storyboard layout name. A visual grid describes panel arrangement, not output aspect ratio.

## 3x3 纯视觉九宫格

- 输出严格三列三行、恰好九格，阅读顺序为从左到右、从上到下。
- 禁止标题、镜号、字幕、参数、UI、水印和签名进入画面；把说明作为独立文本交付。
- 用九格形成建立、触发、推进、核心动作、反应、细节、结果或悬念，不要求机械套用固定节拍位置。
- 覆盖远、中、近或特写以及有叙事作用的机位变化；避免连续三格近似景别、角度或构图。
- 在重建模式中持续携带主参考图，并锁定脸、发型、体型、服装、空间结构、道具、光源和风格。在概念模式中允许纯文字，但把新增细节标为提案。
- 检查九格数量、身份、几何、动作、视线、持物手、道具状态、光线和文字污染。只修正失败格时仍复查全板连续性。

## 故事板表格

- 使用横向、易扫描的制作表；让画面列占主要空间。
- 默认字段为镜号、景别/机位、运镜、分镜画面、可见动作或剧情提示、时长。按项目需要增加场号、节拍、声音、资产和连续性。
- 每镜独占一行；动作提示使用短而可视的句子；底部总时长必须与镜头累计值一致。
- 先生成无字分镜，再确定性排版中文。无法可靠排版时交付无字底图和独立表格，不交付乱码或伪成品。
- 不强制特定手绘颜色体系；服从项目视觉配置和参考证据。

## 视频 Prompt

每镜按以下顺序组织：主体与构图、进行中的动作、必要物理反馈、可见表演、光影变化、对白、声音、兼容模型参数。把稳定外观和空间锚点集中保存在资产清单，不在每镜机械复述。

为每个生成片段提供：

- 片段编号、主轴来源区间、相对生成时间码和目标时长。
- 使用的 `shot_id`、`beat_id`、场景与资产版本。
- 起始承接状态、片内状态变化和结束快照。
- 画幅、镜头、运动、音频、字幕、转场及目标模型参数。
- 仅针对实际风险的负面约束，如身份漂移、服装错误、空间镜像、穿模或多余文字。

不得在完整节拍中间拆片。对白或动作过长时，调整镜头或目标配置；不要通过高速念词、截断直接反应或重置相对分段来掩盖问题。

## 图像能力降级

图像生成或编辑能力可用时，生成后检查非空、画幅、完整取景、格数、身份和空间。能力不可用时输出 `visual-brief-vNNN.md`，明确 `prompt-only`、布局、视觉锚点、证据限制和负面约束。
