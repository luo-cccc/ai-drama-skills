# 单集戏剧合同与写稿纪律

短剧每集都是一次完整的戏剧兑现。本文件定义剧本阶段每集必须携带的合同字段、写稿纪律与质量门的判定口径。它补充引擎的 `schema.md` 与 `script-pass.md`：引擎管"这一集写满了没有"，本文件管"这一集的戏成立没有"。

## 合同是执行，不是再创作

合同大部分字段从已确认大纲确定性搬运——分集梗概、钩子、悬念、爽点认领都在 `outline.json` 里。写手的任务是提炼、补全并把它们落到这一集的节拍上，不是重新规划剧情。任何与大钢冲突的合同字段，都是分集结构出了问题，应该回去改大纲，而不是在剧本层悄悄改口径。

## 合同八字段

| 字段 | 内容 | 要求 |
|:--|:--|:--|
| `incomingState` | 六桶：knowledge / power / relationship / physical / activeAction（可选 emotional） | 上一集 `handoffState` 的事实必须全部接住，只能增补、不能删改。进入状态是连续性边界，不是创作自由 |
| `objective` | character / desiredChange / whyNow | 目标必须是本集内现场可执行的改变；whyNow 说明为什么必须现在 |
| `opposition` | actorOrConstraint / goal / leverage | 阻力方要有自己的目标和筹码，不是一道会自己让路的墙 |
| `causalEscalation` | becauseOf → choice → countermove → stateChange → nextPressure，至少一条 | 升级判据见下 |
| `localDramaticResult` | goalOutcome / stateChange / costPaid | 本集先兑现局部结果，再启动出去压力；必须写代价 |
| `outgoingPressure` | startedDecisionDangerOrQuestion / whyItFollows | 由本集结果产生，不是天上掉下来的新敌人 |
| `handoffState` | 六桶，同 incomingState | 下一集可执行的知识、权力、关系、物理和行动事实；情绪只记会改变下一步行为的情绪选择，不写"更紧张了"这类强度 |
| `informationPermissions` | subject / audience / known / suspected / mistaken / unknown | 观众和人物分开记：谁已知道、谁在怀疑、谁误信、谁还不知道。信息权限是写戏的护栏，也是审计的核对表 |

秘密真相的读者揭示集由 `canon.json` 的 claim 可见性守卫：`secret_truth` 类 claim 在 `reader_known_from` 之前出现在可见正文（动作/对白/旁白），会被剧本导入的机器门拦截。规划字段可以讨论"谁不知道什么"，但观众看到的内容不能提前泄露。反过来，`reader_known_from` 等于本集、正文却没有可见落点的 claim，导入会给出揭示未落地 warning（写稿期用 `script-quality --canon` 自查），最终揭示充分性由 conformance audit 判断。

### 因果升级判据

相邻两拍之间，以下至少一项必须发生**可引用的变化**，否则不能算升级：筹码、知识、关系边界、退路、不可撤回的决定、威胁变成现实。只用更激烈的措辞（"气氛更加紧张"）声称升级，不成立。

### 反转三件套

- **铺垫**：写观众当前会形成的判断，以及本集放下的前置证据。
- **反转**：新信息或新行动推翻那个判断；必须来自人物选择、证据或已建立的世界规则，不能靠临时巧合替人物解决核心困境。
- **后果**：反转后谁失去什么、关系或权力如何变化。没有后果的反转只是炫技。

巧合只能把人物**推进**麻烦（带着代价），不能把人物从麻烦里捞出来；误会必须产生行动，解除时留下残余——没有残余的误会整段可删。

## 情绪钩子与 cliff 的分工

引擎要求每集最后一拍是悬念（`cliff` 字段，引擎门已查"落纸面"）。合同里的 `emotionalHook` 是它的语义层，两者是同一个结尾的两面：

- **cliff** = 最后一拍的具象载体：一句没说完的话、一个没解释的动作、一声来历不明的响。
- **emotionalHook** = 观众看完最后画面时想追问的那个问题，必须指向关系、危险、身份、牺牲或选择。情绪标签（"怅然若失"）或空头承诺（"下集揭晓"）都不是情绪钩子。

情绪钩子按本集的实际运动选型，不要每集轮换模板：

| 类型 | 触发情形 |
|:--|:--|
| 行动钩子 | 人物已在执行一项高代价策略，观众担心它怎么收场 |
| 后果钩子 | 上一集的选择在本集结尾反噬，观众想知道代价有多大 |
| 矛盾钩子 | 话语与证据同时出现且不能同时成立 |
| 关系钩子 | 熟悉的关系出现了新的权力位置 |
| 决定钩子 | 人物必须现在选择，拖延本身有代价 |
| 信息钩子 | 观众获得了一个能重排现场意义的事实 |

## Hook 动作声明

合同的 `hookActions` 记录本集对活跃悬念线的动作，只记真实的操作，不为凑数量硬开新坑：

- `open`：本集打开一个独立新问题，`hookId` 写 `"[new]"`；
- `advance`：推进既有悬念，必须附 1–3 个**画面可见的证据载体**（物件、动作、对白或信息变化），不能用角色名、情绪词或"线索出现"充数；
- `resolve`：回收既有悬念，同样必须附证据载体；
- `defer`：本集明确不动，写理由和预计承接的集数。

回收一个 Hook 不要求开一个新 Hook。向前的拉力来自出去压力和交接状态，不靠钩子配额。

台账本身由机器维护：确认系列大纲时从 major beats 播种 `hook-ledger.json`，每批剧本导入时按合同动作确定性演化（advance/resolve 的证据载体必须在正文落地，缺失即硬错）。技能不得手写台账文件，只声明动作。

## 节拍变奏与爽点轮换

不要每集都走"开场钩子 → 升级 → 反转 → 情绪问题"的同一条曲线。慢热、过渡、后效、布局集允许变奏：

- "反转"槽位可以替换为"压力停滞 + 新威胁压顶"，不要为了凑槽位硬造反转；
- 情绪钩子可以低音量（静默、悬置、按下不表），不必每集以一个问句收尾；
- 一集只改变一个状态维度（信息 / 权力 / 关系 / 生存择一），其余维度保持惯性；
- 变奏集不是弱集：它必须更依赖具体动作与表演细节，禁止用说明文填节奏；
- 慢集不要为了凑满时长硬加镜头或动作，快集不要为了整齐强行放缓；
- `beatsClaimed` 里的爽点类型要与最近几集轮换，打脸 / 揭破 / 兑现 / 揭示 / 底牌不要连续集重复同一类。

## 场景工作卡（写每场前回答）

1. 删掉这场，损失哪一项选择、证据或关系变化？
2. 进入状态是什么？
3. 焦点人物想让谁在本场改变什么？
4. 反对者用什么筹码阻止？
5. 哪个可见动作承载冲突？
6. 哪项事实或决定使原计划失效（方向性转向）？
7. 退出状态给下一场留下什么？

场景可以静，但压力和变化必须可读；台词好听不能替代场景运动。

## 对白即行动

- 写每一句前先回答：说话者想让对方现在做什么、改变什么？没有行动目标的句子，压缩或转成动作。
- 潜台词不是人人说谜语：只有当"真正想做的事不能或不愿直说"时才存在（说出来会暴露秘密、现场有第三人、直接要求会显得没筹码），并且要给观众可推断的线索——避开某个具体词、触碰或藏起相关物件、称呼改变、先答旁枝再回避核心问题。
- 策略必须会受阻：对方看穿点破、接受字面却拒绝隐含的关系、给出反证、改变公开范围。受阻后人物换策略、付代价或退出，不要重复原要求。
- 信息通过争夺、验证、交换、指控、纠正、回避或公开进入冲突，不要向观众复述双方都已经知道的背景。
- 人物声音靠"注意什么、怎样证明、怎样控制距离、怎样隐藏、压力下怎样变形"来区分，不靠口癖词。
- `delivery` 只写可执行策略（试探、逼问、划界、把威胁说成提醒、不让第三人听见、第一次直呼对方名字），不写情绪词——"愤怒""平静""低声"给演员的是情绪，不是动作。
- 长发言只在议程转折处用动作行断开；内部没有转折的长发言应当缩短，而不是拆开。`delivery` 只写"怎么说"，身体动作写进 `action`。
- 功能性路人用描述性标签（陌生人、店员、警察甲）；会继续出场的角色必须复用已注册的名字，不要每集换新称呼。

### 手法的失效条件（用错地方比不用更伤）

- **潜台词**：人物没有隐瞒理由时就直说；无故躲闪只会让观众觉得信息被扣。
- **打断**：被打断的句子若携带观众此后拿不到的信息，改用动作、物件或分镜节奏承载，不要靠打断藏信息。
- **沉默**：沉默必须有可见对象——观众要看得出人物在权衡、等待或判断什么；无对象的沉默只是停拍。
- **先承认一部分**：只在观众已经察觉有更大秘密时使用；否则揭露时观众会觉得被耍。
- **借第三人施压**：引用的规则或第三方筹码必须是观众此前已经知道的；临时发明的挡箭牌等于作者救场。

## 叙事驱动力五因子（大纲阶段纲目）

创作动力由五个因子相乘：**题材前提差异 × 熟悉爽点 × 高压关系 × 因果反转 × 情绪钩子**。乘法意味着任何一个因子长期为零，读者动量就会崩塌；但它不等于要求每集机械地五样全查——那是规划层的审计口径，不是写稿时的填表。

大纲阶段用这五个因子过每一集的梗概：前提差异改变了本集的哪个选择或代价？爽点兑现了哪种熟悉欲望？哪组关系被真实利益压着、双方都走不掉？反转重估了什么？结尾的观众问题是什么？五个问题都答不上来的集，是结构性水集。

## 三层校验分工

| 层 | 执行者 | 决定什么 | 失败表现 |
|:--|:--|:--|:--|
| 确定性结构门 | 引擎 validate + `script-quality` + 合同校验 | 格式成立、合同成立、硬门通过 | import 硬错，无法收编 |
| 创意复核 | `ai-drama-script-audit` conformance 模式 | 戏成立：因果、人物、场景、可拍性、对白 | FIND-NNN 证据化结论，P0 阻断 |
| 治理门 | import 的哈希 / scope / 授权 / prompt-context 校验 | 收编成立：来源、版本、授权链完整 | import 硬错 |

机器门的成功永远不构成审计结论；审计的通过也不免除机器门的重跑。
