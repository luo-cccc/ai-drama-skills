## 视觉总原则

- 影像气质：都市现实、生活流、克制、轻暖、不甜腻。
- 镜头风格：多用固定、中近景、轻微推拉；少用花哨运动。
- 情绪表达：优先靠空间距离、沉默、物件、手部动作、手机屏幕、眼镜、小黑完成。
- 色彩走向：办公楼偏冷白/灰绿；夜晚加班偏荧光冷暖混杂；出租屋偏旧暖低照度；指南针咖啡馆偏午后暖光。
- 核心物件视觉链：眼镜 → 名片 → 线/工具箱 → 创可贴 → 小黑 → 咖啡杯/猫包 → 旧笔记本。
